Subestación 138 kV

Sistema de Transmisión con Redundancia N+1

Descripción del Proyecto

Construcción y comisionamiento de una subestación de transmisión 138 kV para un operador de red independiente (IPP). El proyecto fue diseñado con arquitectura N+1 para garantizar máxima confiabilidad y disponibilidad, cumpliendo con regulaciones estrictas del sector eléctrico.

La implementación incluyó sistemas de protección diferencial avanzados, protecciones contra islamiento no intencional y sistemas de supervisión SCADA integrados con el operador del sistema nacional.

Información Clave

  • Sector: Utilities
  • Tipo: Transmisión
  • Duración: 18 meses
  • Estado: ✓ Operacional

Desafíos y Soluciones

Desafío

Cumplimiento de regulaciones estrictas del regulador de electricidad y sincronización con operador del sistema nacional en tiempo real.

Solución

Trabajo colaborativo con regulador desde fase de diseño, pruebas exhaustivas bajo supervisión de entidad reguladora, y comisionamiento sincronizado con operador del sistema.
